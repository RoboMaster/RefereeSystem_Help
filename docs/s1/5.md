# 1.5 电源管理模块故障

**通道说明：**
- *CH0*对应*Chassis*底盘通道
- *CH1*对应*Gimbal*云台通道
- *CH2*对应*Ammo-booster*发射机构

|  故障类别  |  解决方案  |
|  ---  |  ---  |
|  底盘过载  <br>云台过载 <br>发射机构过载 |  请自行检查该通道接入电路是否存在短路或电流过大，<br>如该通道没有接外置电路则建议直接更换对应电源管理模块  |
|  底盘自检错误 <br>云台自检错误 <br>发射机构自检错误  |  请自行检查该通道接入电路是否存在反向供电，<br>如该通道没有接外置电路则建议直接更换对应电源管理模块  |
| 芯片超温保护 | 检查负载功率是否过大，更换到良好的散热环境下测试
