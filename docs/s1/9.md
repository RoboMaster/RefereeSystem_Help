# 1.9 定位模块故障

- **定位模块基站数量不足**  
请检查定位基站是否全部上电。

- **定位模块置信度低**  
1.  如果赛场上只有极个别UWB报错，检查UWB安装是否符合规范，使用频谱仪扫描机器人，确认机器人上是否有3.75G到4.25G频端的无线干扰，如果都没有，更换UWB模块
2.  如果赛场需要机器人报该错误，检查所有8个基站是否在线，8个基站供电是否正常，同步站是否正常
3. 如果赛场大部分机器人报该错误，检查UWB基站灯效是否正常，如果出现有红灯常亮和红灯闪烁，使用频谱仪扫描场地无线环境，确认机是否有3.75G到4.25G频端的无线干扰，确定有无线干扰后，需要找到干扰源，并关闭该设备。

- **定位模块未校准**  
1. 在主控模块的功能页面下，按如下操作，进入定位模块校准设置页面。
![](A18.png)
2. 在该页面下，选择“定位指南针校准”，则会进入定位模块校准状态。
3. 保持定位模块水平方向（Pitch 轴和 Roll 轴角度小于 10°），在原地沿着定位模块 Yaw 轴旋转
360°。
4. 完成校准后，定位模块的 SYS 灯效为绿灯快闪（2HZ）；若 SYS 灯效为绿灯为慢闪（1HZ）则说明校
准失败。
5. 若校准不成功请重复上述步骤，或者参考最新高校系列赛机器人制作规范手册中的定位模块安装规范，
检查定位模块的安装是否规范。
